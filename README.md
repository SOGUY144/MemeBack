# MemeBack

ครูตั้งคำถามปลายเปิด → นักเรียนตอบด้วยความคิดตัวเอง → AI แปลงคำตอบเป็น **สตอรีบอร์ด** → แอปเรนเดอร์เป็นมีมสั้น ๆ → ทั้งห้องทายว่ามีมนั้นสื่อถึงหลักการอะไร → ครูเฉลย

```
Student Answer → AI Analysis → Meme GIF → Class Guess → Teacher Reveal
```

AI ไม่เคยแต่งคำตอบให้นักเรียน มันแค่ **เข้ารหัสความคิดของนักเรียนใหม่ให้เป็นภาพ** คำตอบว่างหรือไม่เข้าเรื่องจะถูกบอกตรง ๆ ว่าไม่เข้าเรื่อง ไม่ใช่สร้างฉากมั่วขึ้นมา

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env
npx prisma db push
npm run seed
npm run dev
```

เปิดสามลิงก์นี้ (อยู่ในผลลัพธ์ของ `npm run seed` ด้วย):

| บทบาท | URL |
| --- | --- |
| ครู | `http://localhost:3000/host/MEME01?key=demo-teacher-key` |

## ให้นักเรียนเข้าจากมือถือ

เซิร์ฟเวอร์ bind `0.0.0.0` อยู่แล้ว เครื่องที่อยู่วงเดียวกันเข้าได้เลย
จอฉายไม่ได้ใช้ `localhost` ทำ QR แล้ว — มันถาม `/api/join-url` เพื่อเอา IP วงในของเครื่องที่รันเซิร์ฟเวอร์
แล้วโชว์ URL เป็นตัวหนังสือใต้ QR ไว้ด้วยสำหรับคนที่สแกนไม่ติด

```
http://192.168.1.20:3000/play/MEME01
```

ถ้าเสิร์ฟผ่าน tunnel หรือชื่อโดเมนจริง ให้ตั้ง `PUBLIC_ORIGIN` ทับ

**HTTP บน LAN ไม่ใช่ secure context** → `VideoEncoder` ใช้ไม่ได้ ทุกเครื่องจะตกไปใช้ gif.js
(ไฟล์ราว 582KB แทน 55KB) ยังเล่นได้ปกติ แค่ช้ากว่า ถ้าอยากได้ไฟล์เล็กต้องเสิร์ฟผ่าน HTTPS

## สคริปต์เดโม

1. `npm run seed` สร้างห้อง `MEME01` พร้อมคำถามกฎข้อที่ 3 ของนิวตันไว้แล้ว
2. เปิดจอฉาย — จะเห็นรหัสห้องตัวใหญ่กับ QR
3. ให้เพื่อน 3 คนเปิด `/play/MEME01` จากคนละเครื่อง (หรือคนละหน้าต่าง incognito) แล้วใส่ชื่อเล่น ชื่อจะโผล่บนจอฉายทันที
4. ครูกด **เริ่มให้ตอบ** (หรือกด `Space`)
5. ให้แต่ละคนตอบต่างกัน เช่น
   - `กระโดดออกจากเรือแล้วเรือถอยหลัง` → `correct`
   - `Tung Tung กระโดดเตะ Cappuccina แล้วทั้งคู่กระเด็นคนละทาง` → `correct`
   - `ผลักกำแพงแล้วกำแพงไม่ขยับ เลยไม่มีแรงปฏิกิริยา` → `misconception` และถูกดันขึ้นจออัตโนมัติ
   - `ไม่รู้` → `off_topic` ไม่มีมีม ได้ปุ่มให้เขียนใหม่แทน
6. ครูกด **ปิดรับคำตอบ** → **ให้ดูมีมของตัวเอง** → **เริ่มให้ทั้งห้องทาย**
7. ทุกคนทาย (ยกเว้นเจ้าของมีม) คะแนนโหวตขึ้นสดบนจอฉาย
8. ครูกด **เฉลย** เห็นคำตอบต้นฉบับ ผู้เขียน และประเด็นสอนจาก AI แล้วกด **มีมถัดไป** จนครบ
9. **ดูตารางคะแนน**

`Space` = ไปขั้นถัดไป ไม่ต้องละสายตาจากห้อง

## ตรวจเครื่องเรนเดอร์โดยไม่ต้องมี API key

`http://localhost:3000/dev/scenes` มี SceneSpec เขียนมือครบทุกรูปแบบมีม พร้อมแสดงผลลัพธ์ของ timeline compiler (ลำดับเวลาจริง และบีตที่ระบบแทรกให้อัตโนมัติ)

ติ๊ก **ฟิล์มสตริป** เพื่อดู 6 เฟรมเรียงกัน — โหมดนี้ไม่ใช้ `requestAnimationFrame` จึงใช้ตรวจในแท็บที่ไม่ได้อยู่หน้าจอ หรือแคปหน้าจอได้

### ทำไมเรนเดอร์ที่ฝั่งเบราว์เซอร์

`gif.js` เป็นไลบรารีฝั่งเบราว์เซอร์ และมีมของแต่ละคนเรนเดอร์บนเครื่องของเจ้าของคำตอบเอง เสร็จแล้วอัปโหลดกลับผ่าน socket ไปเก็บที่ `public/memes/<answerId>.<gif|mp4>` แปลว่างานหนักกระจายไป 30 เครื่อง แทนที่จะกองที่เซิร์ฟเวอร์เครื่องเดียว

เครื่องไหนเข้ารหัสไม่ทัน 8 วินาที จะยกเลิกและปล่อยให้ `memeUrl` เป็น `null` จอฉายจะเล่นฉากสดด้วย Pixi แทน ห้องไม่ต้องรอ

### สิทธิ์

เปลี่ยนเฟสได้เฉพาะ socket ที่ยืนยันด้วย `teacherKey` เท่านั้น ถ้า socket ของนักเรียนส่ง `teacher:phase` มา เซิร์ฟเวอร์ปฏิเสธที่ตัวมันเอง ไม่ใช่แค่ซ่อนปุ่มใน UI

| --- | --- |
| ทายถูก | 100 ลบวินาทีละ 2 ต่ำสุด 40 |


ครอบสองจุดที่พังง่ายที่สุดตามที่สเปกเตือน:

- **timeline compiler** — บีตกลายเป็นเวลาสัมบูรณ์ถูกไหม, ชื่อ clip ที่โมเดลมั่วถูกแมปกลับไหม, ปฏิกิริยาของเป้าหมายถูกแทรกตอน impact ไหม, ตัวละครยังอยู่ในเฟรมไหม
- **Zod SceneSpec** — ปฏิเสธ verdict/sprite/ฉาก/รูปแบบมีมที่ไม่มีจริง จำนวนตัวละครและบีตเกิน ช่วงเวลานอกขอบเขต ข้อความยาวเกิน และข้อความที่ไม่ใช่ JSON

## จุดที่ตัดสินใจต่างจากสเปก (และเหตุผล)

1. **`clip` ถูกแปลงแทนที่จะถูกปฏิเสธ** — สเปกให้ Zod ใช้ `ClipEnum` แต่ก็ให้ compiler มีตารางคำพ้อง ถ้า Zod ปฏิเสธทั้งฉากเพราะโมเดลเขียน `hit` แทน `punch` สตอรีบอร์ดดี ๆ จะถูกทิ้งทั้งอัน ตอนนี้ `clip` ถูกแมปผ่าน `resolveClip` ก่อนตรวจ ฟิลด์อื่นยังปฏิเสธเต็มที่ตามเดิม

2. **CLASS_GUESS แสดงคำบรรยาย** — ตาราง §5 บอก "caption hidden" แต่ acceptance §11.9 บอก "caption visible but the concept nowhere on screen" ผมยึด §11.9 เพราะกฎข้อ 5 ของ system prompt ห้ามไม่ให้คำบรรยายเอ่ยชื่อหลักการอยู่แล้ว การโชว์จึงปลอดภัยและทำให้ทายได้จริง (คอมโพเนนต์ยังมี `hideCaption` ให้สลับได้)

3. **`jump` ที่มีเป้าหมายทำให้เป้าหมายกระเด็น** — เดิม `jump` ไม่มี `impact` ทำให้ "กระโดดออกจากเรือแล้วเรือถอยหลัง" ตาม acceptance ข้อ 4 ไม่เกิด knockback ที่เรือ การกระโดดใส่อะไรสักอย่างคือการถีบมันออก ซึ่งตรงกับกฎข้อ 3 พอดี

4. **โมเดลเริ่มต้นคือ `claude-sonnet-5`** — สเปกเขียน `claude-sonnet-4-6` ซึ่งเป็นรุ่นเก่ากว่า เปลี่ยนได้ด้วย `ANTHROPIC_MODEL`

5. **ไม่มีเว็บฟอนต์** — ใช้ `Noto Sans Thai` / `Leelawadee UI` / `Segoe UI` ที่มีอยู่ในเครื่อง เพื่อให้แอปบูตได้บนโน้ตบุ๊กโรงเรียนที่ต่อเน็ตไม่ได้

## หมายเหตุ

- บังคับใช้เส้นทาง gif.js บนเบราว์เซอร์ที่รองรับ WebCodecs ได้ด้วย `localStorage['memeback:force-gif'] = '1'`
- ไฟล์มีมและ `public/gif.worker.js` ไม่ถูก commit — `gif.worker.js` ถูกก๊อปมาจาก `node_modules` ตอน `npm install`
- นักเรียนไม่มีบัญชี มีแค่ชื่อเล่นกับรหัสห้อง `playerId` เก็บใน localStorage เพื่อให้ต่อกลับได้เป็นคนเดิมเมื่อเน็ตหลุด
